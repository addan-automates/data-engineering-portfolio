# Supplier CSV Data Margin Processor

## 📌 Project Overview
E-commerce operations frequently depend on daily flat-file legacy spreadsheets generated by third-party logistics warehouses and product suppliers. These source files are fundamentally incompatible with direct storefront ingestion systems due to unmapped header conventions and non-retail wholesale billing metrics.

This production-grade script serves as a robust extraction, transformation, and loading (ETL) utility. It processes arbitrary supplier catalog listings, wraps calculations in automated error boundary zones, maps properties onto Shopify-compliant schemas, and exports clean downstream manifests ready for zero-latency store uploads.

## 🛠️ Data Engineering Process Flow



1. Ingestion Layer: Establishes multi-platform stream compatibility utilizing `newline=''` protocols and reads dynamic properties into standard mapped memory sets via `csv.DictReader`.
2. Validation & Isolation: Evaluates row parameters inside an iterative error checking loop to defend data integrity against corrupt pricing blocks (`ValueError`).
3. Schema Realignment: Re-indexes raw keys onto target specifications (`sku`, `retail_price`, `stock`) and handles numeric precision adjustments.
4. Export Layer:Outflows verified structural updates via `csv.DictWriter` utilizing predefined `fieldnames` layouts.
